# DTS-HD Master Audio remains unqualified

Read-only ffprobe inspection covered 845 candidate files in Movies and Downloads: 734 probeable, 111 malformed/standalone-fragment failures. Extensions: 679 MP4, 154 MOV, five MKV, four WebM, two M4A and one M4V. No DTS track, including no DTS-HD MA profile, was found among the probeable files. Failures and the complete inventory are retained in [search results](dts-search.json) and [summary](dts-search-summary.json). This is not a claim about the undecodable contents of malformed files. The local FFmpeg encoder list has `dca` (DTS core), MLP and TrueHD, and no HD-MA encoder.

No HD-MA profile is admitted. In the codec-ON Matroska path, unqualified packet geometry refuses as `SoftwareAudioPacketTimelineUnqualified` before descriptor publication. The shipped codec-OFF path additionally refuses `SoftwareAudioStageNotBuilt`. Libavformat's DTS audio ingress is not admitted. Complete packet size must equal the DTS core header's byte count: a core plus extension packet cannot silently truncate to core. Extension-only sync is also outside the accepted 16-bit big-endian core signature. The existing packet regression accepts a 1,024-byte core with 512 frames and rejects a 2,048-byte packet carrying that core header. A temporary mutant permitting trailing bytes fails with rc=7; byte-identical restoration passes. [Proof](dts-extension-revert-proof.json). This is a fail-closed boundary test, not an HD-MA decode qualification.

Admission requires a retained real HD-MA specimen and stream index, asset SHA-256 and ffprobe profile facts; full MA decoding rather than the embedded core; exact retained sample counts against FFmpeg decoding that same complete track; zero-frame PCM alignment and the retained numerical tolerances; channel-role/downmix proof; exact equal video/audio endpoints (|V−A|=0); forward, backward and near-EOS seeks landing at A=ceil(T×R)/R; and clean EOS with no duplicate priming or tail clipping. Until those proofs exist, the shared `Dts` codec identity does not broaden the admitted core profile.
