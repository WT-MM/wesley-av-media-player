## Executed build

`scripts/build_ffmpeg_lgpl.sh` is the authoritative argument vector. The exact
shell-escaped [configure command](phase2/configure-command.txt),
[build receipt](phase2/build-receipt.txt), configuration headers, license texts
and [notices](phase2/FFMPEG_NOTICES.md) are retained alongside the report.
The local build took 36 seconds with four jobs, installed 6.2 MiB into
`third_party/ffmpeg-lgpl/`, and removed its intermediate build directory.
Only libavcodec and libavutil are built. Layout copies and planar-to-interleaved
float conversion need neither swscale nor swresample. libavformat is disabled.
Libraries use the `-wamnative` suffix to prevent basename collisions with the
export and mpv closure. Coexistence of both configurations in one process has
not been accepted; the single-playback-closure requirement below remains a
release blocker. The suffix alone is not that proof. The opt-in target currently links the
libraries eagerly; lazy-stage binding remains required before release.

The native AV1 decoder in this source requires a hardware accelerator
(`libavcodec/av1dec.c`, get_pixel_format). Software AV1 requires a separately
pinned dav1d/libaom dependency. It is not advertised by this build.

## Superseded phase-0 configure sketch

The sketch below is historical; the executed command above disables avformat,
swscale, swresample and all decoders except the explicit whitelist.


Run once per architecture in isolated build directories, with an empty pkg-config
search path and an explicit SDK root. Substitute architecture and staging prefix:

```sh
./configure \
  --prefix="$WAM_FFMPEG_STAGE" \
  --arch="$WAM_FFMPEG_ARCH" --target-os=darwin \
  --cc=clang --cxx=clang++ \
  --extra-cflags='-mmacosx-version-min=13.3' \
  --extra-ldflags='-mmacosx-version-min=13.3' \
  --install-name-dir='@rpath' \
  --disable-static --enable-shared \
  --disable-gpl --disable-nonfree --disable-version3 \
  --disable-autodetect --disable-programs --disable-doc \
  --disable-network --disable-protocols \
  --disable-encoders --disable-muxers --disable-devices --disable-filters \
  --disable-avdevice --disable-avfilter --disable-swresample \
  --disable-hwaccels --disable-videotoolbox --disable-audiotoolbox \
  --disable-x86asm --enable-pthreads
```

WAM supplies bounded custom AVIO; FFmpeg protocols are unnecessary. Software
codec, parser, bitstream-filter and demux components retain their upstream
LGPL defaults. No x264, x265, FDK-AAC, OpenSSL, libass or other external library
is enabled. Disabling standalone x86 assembly avoids an unpinned NASM build
dependency in this initial recipe; measure Intel decode throughput before
shipping. SIMD generated by clang and runtime CPU detection remain enabled.
Built libraries: avcodec, avformat, avutil and swscale; retain swscale only if
the proved adapter needs it. No resampling stage is implied by this dependency.
Apple selection stays in WAM: hardware VT, software VT/AudioToolbox, existing
libvpx where applicable, and only then an explicitly mapped libavcodec stage.
Framework availability alone does not prove a stream can decode.

Configuration defaults are not the final coverage manifest. The future build
must save config.h/config_components.h, configure stderr/stdout, library license
and configuration strings, decoder/demux/parser inventories, source/patch hashes
and every transitive Mach-O load command. Fail if GPL/nonfree/version3 is enabled,
if the license strings disagree across libraries, or if an undeclared external
dependency appears. Archive revalidation and a current security review are
required when the first library implementation is ready to ship.

## Bundle and notices

Keep one coherent FFmpeg ABI closure per playback process. A future mpv transition
must reconcile its FFmpeg dependencies with this closure before either is loaded.
An export CLI with a different configuration must keep an independent subprocess
closure; never link the Homebrew CLI's GPL-enabled libraries into WAM by accident.
Use bundle-relative load commands, audit relocation without Homebrew, sign leaves
inside-out and preserve deep signature verification. Optional stages must remain
lazy, and the current exact native-retirement barrier remains mandatory.

Ship the matching source archive, patches, configure recipe, build environment,
license texts and copyright notices beside the binary download. Include
COPYING.LGPLv2.1 and the relevant third-party notices from the pinned source tree.
The About/licenses UI and download page must identify FFmpeg, its applicable
license, and the exact corresponding-source URL. Preserve user replacement and
relinking rights with documented rebuild, install-name, replacement-library and
re-sign steps. WAM's own licensing/contributor-rights decision remains a release
prerequisite; this document does not choose that license.

The licensing model follows FFmpeg's [primary legal guidance](https://ffmpeg.org/legal.html)
and [license inventory](https://ffmpeg.org/doxygen/trunk/md_LICENSE.html).
The archive lock above, rather than the moving documentation, defines the code
that must be audited. Codec patent and proprietary enhancement questions require
separate review before distribution.

## `--verify-runtime` extension design

Preserve current exit behavior and existing runtime checks. Add a versioned
`native_codec_stages` result with:

- stage implementation, source/configuration hashes, library versions and ABI
  majors, architecture slices, deployment target and license strings;
- canonical bundle-relative resolved paths and complete Mach-O closure;
- required decoder, parser, demuxer and conversion inventories compared with the
  build's immutable manifest, including disabled-stage reasons;
- Apple hardware queries after supplemental registration, labeled capability
  hints; separate bounded specimen decodes prove actual profiles and surfaces;
- no-network bounded-memory known-answer decodes, exact PCM/frame counts and
  sample/pixel digests or explicitly versioned lossy tolerances;
- deterministic missing-stage, hash/ABI/license/configuration mismatch and
  external-dependency error codes. Optional missing hardware is not a corrupt
  installation; a required shipped decoder missing is.

Run checks before creating a player window or audio output. Library validation
must not launch a player-engine fallback, spawn a CLI decoder, or treat a
hardware query as a profile proof. Validate replaced LGPL libraries by ABI and
behavior; do not require the distributor's signature as the only accepted
replacement. Relocated signed app tests and an intentionally absent/corrupt
library matrix must cover the new check before enabling it in release packaging.
