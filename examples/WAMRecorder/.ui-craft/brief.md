# WAM Recorder
A quiet native macOS menu bar utility for repeated 90-minute audio sessions.
User requires independently configurable microphone and system audio, one session
at a time, and a measured energy-efficient default. System typography, native
controls, standard light/dark appearance; red is reserved for active recording.
Elapsed time and recorded-source labels communicate state without constant animation.
Source tracks remain separate. Five-minute file checkpoints limit crash exposure.
